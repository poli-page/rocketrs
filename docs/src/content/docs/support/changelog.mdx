## Versioning

`poli-page-rocket` shares its major.minor with the Poli Page API: crate `0.13.x` talks to API `0.13` and requires `poli-page` `0.13`. Patch numbers are free. A change of the API contract, a new feature, and a raise of the minimum Rust (MSRV) or Rocket version are each a minor.
